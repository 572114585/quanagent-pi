# Schedule reference

The scheduling design and five-field Vixie cron semantics reference DeepSeek Harness Schedule:
https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/schedule/schedule

The local TypeScript implementation uses `@js-temporal/polyfill` 0.5.1 and adapts the timing behavior to pi's process-owned host and original-session execution. The upstream license is reproduced for attribution:
